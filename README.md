Background:  
Ballapit faced challenges with user retention in a competitive market. This case study was done to identify data-driven growth opportunities.

Project Narrative:  
I analyzed 3 months of user behavior data using SQL and Excel. I mapped the user funnel, ran cohort analysis, and compared Ballapit’s metrics to industry benchmarks.

conclusions:
